# CSD-440 - Server-Side Scripting
Repository for CSD 440 - Server-Side Scripting for Wade Eckert.  

This repository contains my coursework and programming assignments completed for **CSD 440 - Server-Side Scripting** at Bellevue University. Throughout this course, I learned how to build dynamic, database-driven web applications using PHP while applying modern web development practices. Assignments progressed from fundamental PHP syntax and server-side scripting concepts to complete CRUD applications that interact with relational databases.

## Topics Covered

Throughout this course, I gained practical experience with:

- PHP programming fundamentals
- Variables, data types, operators, and control structures
- Functions and reusable code
- HTML form processing and server-side validation
- Sticky forms and user input validation
- Arrays and associative arrays
- Working with JSON data
- PHP sessions and state management
- File handling
- Database connectivity using MySQL
- SQL queries and prepared statements
- CRUD (Create, Read, Update, Delete) application development
- Dynamic HTML generation using PHP
- Separating application logic from presentation
- Basic web application security and input validation

## Major Projects

Some of the larger projects completed during this course include:

- Dynamic customer information management applications
- Database-driven player management system using MySQL
- Baseball statistics database application featuring search functionality, dynamic table generation, and record insertion
- Multi-page PHP applications using reusable templates and shared components
- PDF generation and document export using the FPDF library

These projects demonstrate the progression from introductory PHP programming to the development of complete server-side web applications that interact with relational databases.
